Translate a KiriKiri-KAG project

This workflow is optimized for readable KAG projects where you have the real .ks scenario files.

0) Start with the real script files

Do not begin from a random packed release if you can avoid it.
First confirm you can open the target .ks files as readable text.

1) Backup

  • Zip the whole script folder, or
  • initialize a git repo before you export any translations

2) Translate safely

Option A: Direct translator flow

  1. Open KiriKiri-KAG Translator
  2. Upload one small .ks file first
  3. Translate and export it
  4. Put it back into the project and test the scene

Option B: Extractor review flow

  1. Open KAG Dialog Extractor
  2. Inspect only the extracted dialogue and names
  3. Translate after you confirm the parser is touching the right strings
  4. Merge back and compare the result

3) QA checklist

  • commands like @jump, @if, and @call still exist
  • inline tags such as [r], [p], and [cm] are unchanged
  • labels, IDs, and file references were not translated
  • quotes, escapes, and line breaks still behave correctly

See: Formatting & placeholders

4) Test in-game

  • Run the game and open the scenes you changed
  • Check narration, names, choices, and message flow
  • If a scene fails, compare the translated file with the original around the changed lines
